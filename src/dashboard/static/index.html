Model

DetailsA mixture-of-experts model: 24 layers of 60 routed experts, 4 used per token, plus a shared expert. Int8 weights: 14.36 GB on disk. Model by the Qwen team (Tongyi Qianwen license).

DetailsBuilt in a temporary folder when first used: 3 layers of 8 experts. It runs the same engine code (store reads, cache, prefetch, cancellation) as Qwen. In Advanced.
Execution
LeanMoE Our ExpertRelay-derived method: keeps experts in a RAM cache and prefetches likely upcoming ones.
DetailsExperts are read from the SSD with unbuffered I/O into a fixed-size cache; a predictor starts reading the next layer's likely experts early. The cache can shrink or grow during a run when the memory budget changes.
Windows paging The baseline: memory-mapped expert files, without our cache or prefetch.
DetailsThe whole model file is memory-mapped and Windows loads pages on demand, keeping them in its file cache. Speed depends on what is already cached; private memory is low, physical RAM use can be high.

Comparison details and limits

One run of each method, one after the other, each from a fresh model load, with the same prompt and settings. Windows-paging speed depends on what Windows already has in its file cache, so earlier runs and the order affect it; a single comparison is not a benchmark. Paging keeps weights in the file cache, so its private memory is low while its working set (physical RAM) can be high. The recorded benchmark on the Evidence tab used repeated, alternating runs.

    What these results do and don't show

    Recorded results come from one 8 GB Windows laptop and a few prompts. Output equality was tested for those prompts with greedy decoding; it is not a general correctness guarantee. Timings vary with background load and with Windows' file cache. The engine tests check its mechanisms on a synthetic model, not the real model's quality or speed.
