    Engine tests

    The engine tests build a tiny random-weight model in a temporary folder and run the real engine code on it (cache resizing, live budget, output preservation, streaming, cancellation). They need no model download. In PowerShell, in the repository folder:

    .\.venv\Scripts\python.exe -m pytest

    A good run ends with "passed" and no "failed" or "skipped". They test the engine's mechanisms, not the real model's quality or speed.
